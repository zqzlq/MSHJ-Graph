# MVP 演示脚本

## 1. 项目定位

本 MVP 面向数字经济新一代信息技术岗位，演示“多源 JD 数据输入 -> 岗位能力图谱 -> 新岗位发现 -> 既有岗位更新 -> 简历解析 -> 人岗匹配建议”的闭环。

## 2. 演示流程

1. 打开首页，查看岗位数、JD 数据源数、简历样例数和图谱节点数。
2. 查看“岗位能力卡片”，说明系统已内置一个新兴岗位“AI Agent 应用工程师”和一个既有岗位“Java 开发工程师”。
3. 查看“新岗位发现”，展示系统如何从 Agent、RAG、工具调用、多智能体等信号识别新兴岗位。
4. 查看“能力图谱”，说明岗位、技能、技能类别和行业场景被结构化为图谱节点和关系。
5. 查看“既有岗位动态更新”，说明 Java 岗位从 2024 到 2026 新增 Kubernetes、可观测性、大模型 API 集成等能力。
6. 在“人岗匹配与学习路径”中选择目标岗位，运行样例简历匹配，展示匹配分、已覆盖技能、缺口技能和学习路径。

## 3. 当前 MVP 边界

- 数据量为演示级样例，后续可扩展到 100 条以上 JD 与测试用例。
- 解析算法以可解释规则和技能词典为主，后续可接入大模型抽取、RAG 和多源交叉验证。
- 文本简历已可解析，PDF/Word 可在后续增加文件上传与文档解析模块。

## 4. 后续比赛增强方向

- 扩充多平台 JD 采集、去重、时效性加权和抄袭识别。
- 引入大模型结构化抽取，并强制返回证据片段，降低能力幻觉。
- 增加图谱人工校正后台，支持岗位定义和技能项审核。
- 将测试集扩展到至少 100 条 JD 和多类简历，输出准确率评估报告。
